# 🏡 W&C 家庭記帳本 (Family Accounting System)

專為 **Willie & Christine** 設計的雲端家庭記帳系統，採用 **Percento** 風格的質感卡片與百分比配置視覺化設計，並以你的私人 **Google Sheet** 作為雲端資料庫與「家庭總帳本」自動統計中樞。

---

## ✨ 核心功能亮點

1. **Percento 風格視覺化總覽**
   - 頂部月度財務總覽大卡：即時呈現當月總支出、總收入、淨結餘與月預算執行率。
   - **成員支出佔比**：自動統計 **Willie**、**Christine**、**共同** 各自的當月支出金額與比例（支援在設定中自由改名或新增成員）。
   - **百分比分類配置條 (Allocation Bar)**：直覺檢視各主分類佔比，點擊分類卡片即可展開**子分類比例**或一鍵跳轉篩選明細。
2. **🔍 手機秒速搜尋與多維度查帳**
   - 支援關鍵字即時檢索（備註、店名、分類、金額），並可依「全部歷史月份 / 當月」、「支出 / 收入」、「成員」、「主分類」交叉過濾，即時加總篩選後的收支總額。
3. **🏷️ 自訂收支分類 + ⚡ 固定收支常用模板**
   - 支援在 App 內自由新增/刪除**主分類**（自選圖示與色票）與**子分類**，自動同步至 Google Sheet。
   - 內建「固定收支 / 常用模板」（如房貸、管理費、水電網路、好市多採買），記帳時 1 秒帶入，或月初點擊「⚡ 一鍵入帳本月固定開銷」批次寫入。
4. **🔐 iPhone Face ID 生物辨識鎖定 + 📲 跨手機無痛換機移轉**
   - 整合 Apple 原生 **WebAuthn (Face ID / Passkeys)**，支援開啟 App 時以 Face ID 快速驗證，並具備家庭通行碼備援解鎖。
   - **專為換新手機與家人配對設計**：在舊手機點擊「📷 顯示換機 QR Code」或「📋 複製一鍵移轉碼」，新手機一掃即自動帶入 Google Sheet API 網址与家庭通行碼，並同步全部雲端歷史帳務！

## 🚀 2 分鐘串接 Google Sheet 家庭總帳本

1. 打開你的 Google 試算表（或新建一份空白試算表作為家庭總帳本）。
2. 點擊上方選單 **「擴充功能 (Extensions)」 > 「Apps Script」**。
3. 將專案中 [`gas/Code.gs`](./gas/Code.gs) 的內容完整貼上，並將頂端的 `DEFAULT_FAMILY_PASSCODE` 修改為你們夫妻專屬的家庭通行碼（例如 `WC-Family-2026`）。
4. 點擊右上角 **「部署 (Deploy)」 > 「新增部署作業 (New deployment)」**：
   - 選取類型：**「網頁應用程式 (Web app)」**
   - 執行身分：**「我 (Me)」**
   - 誰可以存取：**「所有人 (Anyone)」** *(所有讀寫請求皆受你的家庭通行碼保護，且試算表本體保持私人不公開)*
5. 複製部署完成後的 **網頁應用程式網址 (`https://script.google.com/macros/s/.../exec`)**。
6. 打開手機 App 的 **「FaceID/換機 (設定)」** 分頁，貼上網址與家庭通行碼，點擊 **「儲存設定並立即同步雲端」** 即完成！
   - 同步時，Google Sheet 會自動建立三個分頁：
     - `Transactions`：所有收支明細（含自動切好的 `YearMonth` 欄位）
     - `Monthly_Summary`：**家庭總帳本月度自動彙總表**（已內建動態 `SUMIFS` 公式，自動統計當月總收支、Willie/Christine 各自支出與各分類總額，再也不用每個月手動搬帳！）
     - `App_Config`：自動備份你們自訂的分類、子分類、成員與常用模板。

## 📱 如何加到 iPhone 主畫面 & 換新手機移轉

### 加到 iPhone 主畫面 (像原生 App 一樣全螢幕使用)
1. 用 iPhone **Safari** 打開本系統網址。
2. 點擊底部中間的 **「分享」** 圖示 > 選擇 **「加入主畫面 (Add to Home Screen)」**。
3. 進入 App「FaceID/換機」分頁，點擊 **「啟用 / 綁定本機 Face ID」**。

### 近期換新手機 / 幫 Christine 設定手機
1. 在已設定好的手機上，進入 **「FaceID/換機」** 分頁。
2. 選擇配對目標身分（`Willie` 或 `Christine`），點擊 **「📷 顯示換機 QR Code」**。
3. 拿**新 iPhone 相機**直接掃描該 QR Code（或複製 `FAS1:...` 移轉碼貼到新手機），**1 秒自動完成連線設定並從 Google Sheet 載入所有歷史帳務**！
4. 在新手機上點擊「啟用 / 綁定本機 Face ID」即可無縫接軌使用。
